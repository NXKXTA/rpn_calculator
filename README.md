# Калькулятор с обратной польской записью

Калькулятор преобразует обычное математическое выражение в обратную польскую запись (ОПЗ), а затем вычисляет её с помощью стека.

## Возможности

- операции `+`, `-`, `*`, `/`, `%` и `^`;
- круглые скобки;
- целые и десятичные числа;
- унарные `+` и `-`;
- приоритет операций и правильная ассоциативность степеней;
- понятные сообщения об ошибках.

Оператор `^` обозначает возведение в степень. Показатель степени должен быть целым числом.

## Запуск калькулятора

```bash
python calculator.py
```

Пример:

```text
Введите выражение: (2 + 3) * 4
ОПЗ: 2 3 + 4 *
Результат: 20
```

## Как устроена программа

1. `tokenize()` разбивает строку на числа, операторы и скобки.
2. `infix_to_rpn()` преобразует выражение в ОПЗ алгоритмом сортировочной станции (shunting-yard).
3. `evaluate_rpn()` вручную обрабатывает токены ОПЗ с помощью стека: достаёт операнды, выполняет одну операцию и кладёт результат обратно.
4. `calculate()` объединяет преобразование и вычисление.

Встроенные `eval()`, `exec()` и `pow()` не используются. Возведение в целую степень реализовано отдельным алгоритмом повторного возведения в квадрат.
